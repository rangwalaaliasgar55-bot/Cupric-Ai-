# SaaS video templates

These are NewBrand-authored, editable Studio storyboards for common SaaS video jobs:

- Launch announcement
- Feature drop
- Product demo
- Problem to solution
- Customer testimonial
- Pricing CTA
- Changelog release
- Onboarding walkthrough

Select the `saas-video` pack in Library and add a template to the Studio. Each scene becomes a real text clip with editable timing, copy, typography, animation, and highlight word. Add imported screen recordings or UI Lab snapshots on the media/overlay tracks to complete a full product video.
