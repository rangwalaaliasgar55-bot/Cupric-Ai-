# dashi-motion attribution and usage boundary

This directory preserves the main documentation and inspection helpers from [chuspeeism/dashi-motion](https://github.com/chuspeeism/dashi-motion), commit `44ba9176ae3f925f3082c5639ef09ca60309eaa6`, authored by `jadon7`, because the user explicitly requested that Cupric learn from this repository.

The upstream repository does not declare a software license in its GitHub metadata and does not include a `LICENSE` file. It must not be treated as MIT or as a general permissive source. These files are retained inside Cupric for attributed, reference-only agent guidance; Cupric does not execute its After Effects, Rive, or Cavalry helpers automatically, and does not claim those external applications are installed.

The autonomous agent uses a Cupric-authored distilled playbook in the generated resource pack. The original reference material remains available here for human review, with the upstream link and commit pinned above.
