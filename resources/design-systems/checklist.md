# Minimum design-system checklist (app)

- [x] Tokens: color, type, space, radius, shadow, motion
- [x] Components: button, input surface, card, dialog, empty, skeleton states
- [x] Patterns: forms, modals, nav, toasts (once)
- [x] A11y: 44px targets where possible, contrast, keyboard, focus ring, labels
- [x] Docs: DESIGN.md source of truth
- [ ] Reject any screen that invents a 6th color or 3rd font
