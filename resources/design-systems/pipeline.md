# Design resource pipeline (order matters)

Do not use all 15 sites as a pile. Use as a pipeline:

1. **System** — Open Props scales, Utopia fixed midpoint, Design System Checklist, one reference from designsystems.one → `DESIGN.md` + `src/styles.css`
2. **Layout target** — VibePrompt named layouts, Component Gallery anatomy
3. **Building blocks** — one kit (NewBrand local / optional coss or ReUI for complex surfaces only)
4. **Motion** — Kinetics/Motion Primitives moments only → `src/lib/motion.ts`
5. **Finish** — Rauno checklist, UI Skills playbooks, bg.ibelick stage-only

NewBrand already locks Layer 1 + motion + finish in DESIGN.md.
