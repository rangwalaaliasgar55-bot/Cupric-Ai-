# React Bits capability index

This directory contains discoverability metadata for the React Bits catalog. Upstream source is **not vendored** because its MIT + Commons Clause license prohibits selling, sublicensing, or redistributing the components themselves, alone, bundled, or ported. Each entry links to the attributed upstream page and generates an original deterministic Cupric Studio storyboard made from native editable clips; it is not a copy or port of the upstream implementation.
